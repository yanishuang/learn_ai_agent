# 第 13 章：产品体验、企业集成与生产治理

## 本章定位

本章把可运行的 Agent 系统推进为用户能够理解、控制和信任的产品，并补齐企业部署所需的治理边界。重点是任务创建、进度反馈、引用与审批体验，以及租户、成本、数据和事件响应的生产控制。

## 前置知识

学员应已完成第 8 章到第 10 章，能够读取 Workflow 状态、Agent trace、引用和 MCP 工具结果。学员还应熟悉 FastAPI、SSE 或 WebSocket 的基本通信方式，以及常见的身份认证和部署概念。

## 学习目标

- 学员能够设计异步任务创建、状态查询、取消、重试和恢复的用户流程。
- 学员能够展示引用、工具活动、审批请求、失败原因和下一步动作。
- 学员能够说明企业 IM 入口与核心 Agent 服务之间的职责边界。
- 学员能够制定密钥、租户隔离、限流、配额、成本预算、数据保留和事件响应控制。
- 学员能够把评估阈值、权限检查和生产检查纳入 CI 与发布流程。

## 核心知识

本章覆盖任务 API 与 SSE/WebSocket 进度流、可撤销和可恢复交互、服务端权威审批、结构化错误呈现、企业入口适配，以及部署与运营治理。Apps SDK 和 MCP Apps 只作为可选交互表面，不能替代业务权限、持久化状态和审计系统。

## 教师演示

教师演示一个长任务从创建、进度更新、工具调用、审批暂停到恢复完成的完整用户旅程，并在中途触发可重试失败。随后教师展示跨租户访问、配额超限和撤销审批如何由服务端拒绝，而不是依赖前端按钮或模型判断。

## 学员实验

学员为 Know-Engine 增加任务状态接口和进度流，前端或命令行客户端必须展示引用、当前步骤、失败原因、取消和重试结果。学员还要提交一份企业集成边界图和一份覆盖部署、密钥、租户、成本、保留与事件响应的生产检查表。

## 失败注入与排错

学员注入客户端断线、重复提交、审批载荷变化、配额耗尽、跨租户访问和下游超时。排错时必须验证幂等键、服务端状态、审批 payload hash、权限记录和 trace 关联关系，不能只刷新页面或重新请求掩盖问题。

## 自动验证

自动验证应覆盖任务状态转换、重复请求幂等性、取消语义、审批一致性、租户隔离、配额拒绝和敏感字段脱敏。流式接口测试应断言事件顺序和终止事件，而不是依赖人工观察页面是否更新。

## 作业与评分

作业总分 100 分，其中任务与进度体验占 25 分，引用和审批可理解性占 20 分，企业集成边界占 15 分，生产治理检查表占 25 分，失败注入与自动测试占 15 分。只有界面截图而没有服务端状态和测试证据不能获得满分。

## Core / Advanced / Production 完成标准

- Core：用户能够创建、观察、取消和重试任务，并理解引用、工具活动和失败原因。
- Advanced：完成一个企业 IM 适配入口或交互式结果表面，同时保持核心服务边界清晰。
- Production：租户隔离、配额、成本、保留、事件响应和 CI 门禁均有可执行控制与验证证据。

## 本章资料

本章资料应覆盖 FastAPI 流式响应、WebSocket、OpenTelemetry、部署平台的密钥管理和企业身份协议。Apps SDK 或 MCP Apps 资料只用于评估交互能力，选型记录必须说明成熟度和不进入核心权限层的原因。

## 复盘模板

复盘时请完整回答：用户如何知道任务正在做什么；失败后有哪些可恢复动作；哪项控制必须由服务端权威执行；当前系统离生产环境最远的治理缺口是什么。
