# 课程准备：环境、运行模式与教学项目

## 本章定位

本单元是十五章课程之前的必修准备单元，负责统一仓库导航、Python 环境、运行模式、成本安全和验证方式。完成本单元后，学员应能在没有 API Key 和网络访问的情况下运行默认练习，并能解释何时才允许切换到真实模型。

## 前置知识

学员需要会使用终端、Git 和基础 Python，并理解 HTTP、JSON 与环境变量的基本含义。不要求具备 Agent 框架经验，也不要求掌握 Go。

## 学习目标

- 学员能够安装 Python 3.12 或更高版本，并使用 `uv` 创建和同步课程环境。
- 学员能够区分确定性的 Fake Model 模式与显式启用的 Live 模式。
- 学员能够运行课程验证和测试，并根据失败信息定位到文件、用例或配置。
- 学员能够说明 API Key、模型选择、调用预算和敏感日志的安全边界。
- 学员能够找到 Know-Engine、Dodo-Agent、实验和评估资料；教学发布版提供时，能够按 `reference-implementation/README.md` 定位参考实现。

## 核心知识

本单元覆盖仓库目录与两种学习路径、`uv` 的环境和锁文件职责、Fake Model 的确定性价值、Live 模式的显式开关、环境变量中的密钥管理、调用成本上限，以及测试失败的读取顺序。Fake 路径应离线、无密钥和可重复；Live 路径必须显式启用，并在模型、预算和脱敏边界确认后才用于对比实验。

## 教师演示

教师从一次干净检出开始，演示环境同步、根目录验证与测试。教学发布版包含 `reference-implementation/` 时，再按其 README 演示 Fake Model 场景，以及缺少 Live 开关时如何拒绝真实调用，并说明日志中哪些字段可以记录、哪些敏感值必须脱敏。

## 学员实验

学员在自己的环境中完成依赖同步，运行根目录验证与测试，并记录 Python、`uv` 和操作系统版本。教学发布版包含 `reference-implementation/` 时，学员再按其 README 定位样例数据、完成 Fake Model 调用，并写出启用真实模型前必须检查的成本与密钥清单。

## 失败注入与排错

学员分别制造 Python 版本不符、依赖未同步和测试断言失败三类问题，再依据错误输出恢复环境。教学发布版的 Live 实验另可制造环境变量缺失；在 `reference-implementation/` 尚未提供的中间提交中，这表示课程材料尚未到教学发布门槛，而不是学员环境损坏。排错记录必须包含现象、根因、修复动作和防止再次发生的验证命令。

## 自动验证

当前可执行基线是根目录命令：`python3 scripts/validate_course.py` 和 `python3 -m pytest -q`。它们不要求 API Key，也不会发起付费模型调用。Fake 与 Live 命令是教学发布的正式门槛：仅当 `reference-implementation/` 存在时，才按该目录的 README 执行；若目录尚不存在，课程材料尚未到教学发布门槛，并非学员环境故障。任何失败都必须先缩小到单个验证项或测试，再重新运行完整命令。

## 作业与评分

作业总分 100 分，其中环境可复现占 30 分，Fake 模式运行证据占 25 分，测试与失败分析占 25 分，密钥和成本安全清单占 20 分。只提交截图而没有命令、版本和错误解释，不能获得对应项满分。

## Core / Advanced / Production 完成标准

- Core：能够从干净环境运行当前根目录基线验证，并解释 Fake 与 Live 的成本和安全边界。
- Advanced：教学发布版提供 `reference-implementation/` 后，能够按其 README 运行确定性 Fake 场景，并说明它如何支持后续回归评估。
- Production：教学发布版提供时，能够按其 README 完成显式 Live 对比，并给出密钥轮换、日志脱敏、预算告警和依赖锁定的可执行检查表。

## 本章资料

本单元以仓库 README、`uv` 官方文档、Python 虚拟环境文档和 pytest 文档为主要资料。教学发布版出现 `reference-implementation/` 后，以其 README 为 Fake 与 Live 命令的唯一依据。阅读时应重点确认安装命令、锁文件语义、测试发现规则和凭据管理建议，而不是复制未经验证的环境片段。

## 复盘模板

复盘时请完整回答：我的默认运行模式是什么，它为何不会产生真实调用费用；我如何证明环境可复现；我遇到的第一个失败是什么以及如何定位；进入第 1 章前还有哪些环境风险没有消除。
